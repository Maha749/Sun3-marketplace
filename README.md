# صُنع — نموذج سوق إلكتروني

## ما يحتويه
- واجهة عربية RTL متجاوبة.
- بحث وتصنيفات وسلة تجريبية.
- شاشات إنشاء حساب/دخول مبدئية.
- بوابة بائع لإضافة المنتجات (تنتظر مراجعة الإدارة).
- شاشة طلبات.
- مخطط قاعدة بيانات أولي وسياسات RLS في `supabase/schema.sql`.

## التشغيل محليًا
1. ثبتي Node.js إصدار LTS.
2. داخل المجلد شغّلي: `npm install`
3. شغّلي: `npm run dev`
4. افتحي الرابط المحلي الذي يعرضه Vite.

## ربط Supabase
1. أنشئي مشروعًا جديدًا في Supabase.
2. راجعي `supabase/schema.sql` مع مطور قبل تنفيذه؛ سياسات الصلاحيات تحتاج استكمالًا واختبارًا قبل أي استخدام إنتاجي.
3. أنشئي ملف `.env.local` بناءً على `.env.example`.
4. ضعي Project URL و anon/publishable key فقط في متغيرات VITE. لا تضعي service_role key في المتصفح.
5. اضبطي تدفق التسجيل وتأكيد البريد وملف المستخدم. لا تمنحي دور admin من نموذج التسجيل العام.
6. أنشئي دالة آمنة transaction-safe لإنشاء الطلب وحساب الإجمالي من الأسعار المحفوظة، وسياسات للبائع لتحديث حالات الطلبات الخاصة بمنتجاته.
7. اختبري صلاحيات كل دور، ورفع الصور، والمدفوعات، والإلغاء والاسترجاع قبل النشر.

## حدود هذه النسخة
هذه حزمة تطوير أولية وليست متجرًا إنتاجيًا. وضع العرض يستخدم بيانات تجريبية. لا يوجد دفع فعلي أو شحن أو لوحة إدارة كاملة. لا تضعي بيانات عملاء حقيقية قبل استكمال الأمان والاختبار.
